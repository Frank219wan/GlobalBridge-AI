## 1. 开场（约 1 分钟）

一句话问题定义：中国中小制造企业出海，卡在"不知道卖给谁、看不懂询盘、报价慢"。
一句话方案定义：GlobalBridge AI 把市场发现 → 客户情报 → 询盘理解 → 双语回复 → 报价串成一条链路，Web 与 Windows 同一套业务数据。

**不展开技术栈**，留到问答。

## 3. 双端一致性（约 1.5 分钟）

这一段是 E 的核心展示点，必须现场做、不能用截图替代：

1. 打开 Windows 桌面端（WebView2 壳），登录同一账号。
2. 直接打开刚才那条报价 → **金额、状态、版本与 Web 完全一致**。
3. 点击一条来源外链 → **在系统默认浏览器打开**，桌面端窗口不跳走。
   口径："壳只负责窗口和导航，业务永远是同一份，所以不存在两端行为不一致。"
4. 在桌面端改一个字段并保存 → 切回 Web 刷新 → 版本 +1。

兜底：若现场网络不稳，先在桌面端展示离线提示与恢复重试，把"异常可恢复"也讲成卖点。

## 4. 异常与边界（约 1 分钟，视时间裁剪）

挑 1–2 个讲，不要全演：

- 断网保存 → 输入不丢，恢复后重试成功，**只产生一条记录**（幂等）。
- 并发改同一条报价 → 旧版本被 409 拦截，不会静默覆盖。
- 历史报价不随产品改价变化（快照）。

## 5. 收尾（约 30 秒）

- 已验证的真实能力：真实检索、真实模型、真实双端。
- 明确边界：单产品、单行报价、文本询盘、英德两语、人工确认——**不吹没做的部分**。
- 下一步：多行报价、文件解析、PDF 导出、完整客户报告。
