## 团队环境复验要求

- 各开发成员根据官方文档检查 Skill / CLI 的安装及版本兼容性。
- 使用经授权的开发凭证，独立确认认证、权限与额度。
- 优先用项目相关的只读搜索进行最小验证，无需读取任何个人账号内容。
- 本地安装路径、认证状态、凭证来源及个人账号数据不写入共享文档。
- 新执行结果与历史基线分别统计，单独验证拟部署环境。
