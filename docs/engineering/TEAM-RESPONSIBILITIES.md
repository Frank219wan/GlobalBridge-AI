# 五人团队分工与交接

依据 2026-11-25 五人版技术设计第 5–6 页。A–E 是岗位代号，不绑定个人姓名；D1–D14 是项目日。A 统筹技术决策与 Web 发布，E 统筹双端验收。各负责人交付可联调页面或接口、测试样例及验证记录。

| 岗位 | 主责 | 交接 |
| --- | --- | --- |
| A 平台与资料 | 登录、会话、企业及产品、Dashboard、数据库迁移、备份恢复、HTTPS 部署 | D2 字段、错误格式、版本规则；D5 工作区、产品 ID、资料接口 |
| B 市场与客户 | 知乎与海外检索、证据核实、市场归纳、市场与客户页面/API、客户去重 | D2 供应商与留存字段；D5 向 C 交付客户 ID、关联产品 ID、可重开报告 |
| C 询盘与商务沟通 | 询盘页面/API、六项提取、证据、追问、用户修订、德英回复编辑与复制 | D2 字段样例；D3 模型及地域；D7 向 D 交付确认询盘 ID、版本及数量 |
| D 报价与历史 | 报价页面/API、金额计算、草稿/确认、幂等、版本冲突、历史快照与回查 | D2 与 A、C 对齐报价字段；D8 开放接口；D9 向 E 交付可保存及可重开报价 |
| E 桌面与双端验收 | WebView2 壳、运行时检测、安装包、全链路回归、异常恢复、演示脚本及排练 | D2 桌面壳联通；D11 可试装包；D12 双端证据；D14 演示材料 |

## 两周排期

| 项目日 | 并行任务 | 阶段通过条件 |
| --- | --- | --- |
| D1–D2 | A 部署/库验证；B 实测搜索；C 模型试调；D 报价规则；E 最小壳试装 | 共用德国传感器样例，冻结字段、留存、预算、Windows 支持范围，记录真实请求 |
| D3–D5 | A 资料产品；B 检索并保存客户；C/D 按样例开发；E 回归脚本 | C 可从市场结果及客户历史进入询盘，核对客户/产品关联 |
| D6–D9 | C 修订确认询盘交 D；D 预填、保存、回查；E 串联 Web 与失败分支 | D7 冻结报价输入；D9 从产品录入走到报价保存并回查 |
| D10–D14 | E 双端回归；A 恢复；B–D 修缺陷；全员排练 | D11 安装包，D12 冻结演示版，D13–D14 复测阻断项并交付 |

交接时提供记录 ID、版本和复现步骤；接收方在同一测试工作区核对。E 汇总阻断项，模块负责人修复。

## 验收责任

| 检查 | 条件 | 主责 |
| --- | --- | --- |
| 外部服务 | 部署环境真实知乎、同批英德查询比较海外候选、核实至少三家德国目标企业官网及主营业务、记录状态/时间/来源/计费 | B |
| 合同与异常 | 会话、字段、过期版本、失效记录、统一错误，跨工作区读写均失败，模拟搜索部分成功/超时/限额 | A、B |
| 询盘及回复 | 德文完整、英文缺项、矛盾三份样本；字段证据一致；下游使用用户修订；双语可编辑复制 | C |
| 报价 | 1,000 × 2.35 EUR = 2,350.00 EUR；空价草稿、拦截负数和超精度、重复只一条、并发旧版本拦截、旧报价价格不变 | D |
| Web 全链路 | 新工作区从录入到回查、异常恢复；可用 Playwright；真实供应商独立验证 | E 牵头，全员复核 |
| Windows 与数据恢复 | 清洁环境安装、同一 Web 服务、登录/外链/复制/网络恢复、双向重登回查报价；独立恢复演练 | E 双端，A 恢复 |
